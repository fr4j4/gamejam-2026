📋 Reglas

  • 01 Cada participante trabaja exclusivamente dentro de participantes/tu-nombre/
  • 02 No tocar archivos fuera de tu carpeta — eso incluye README, .gitignore, etc.
  • 03 En Fase 1: haz un Pull Request con tu juego a main
  • 04 En Fase 2: haz un Pull Request con las mejoras al juego que te tocó
  • 05 @Motoko revisa y mergea ambos PRs
  • 06 No juegos eróticos. Violencia explícita y extrema sí, permitida. Sangre, gore, desmembramiento, todo bien. Pero nada de contenido erótico o sexual.

🚀 Cómo participar

01

Haz fork del repo

Forkea kodingvibes/gamejam-2026 a tu cuenta de GitHub.

02

Clona y crea tu rama

git clone tu fork, luego git checkout -b participante/tu-nombre

03

Codea tu juego

Crea participantes/tu-nombre/ y desarrolla todo ahí. HTML, Phaser, Python — lo que quieras.

04

Sube tu rama y haz PR

git push origin participante/tu-nombre y crea un PR hacia kodingvibes/gamejam-2026:main

05

@Motoko revisa

La IA del grupo revisa tu PR. Si pasa los filtros, se mergea automáticamente.

✅ Criterios de validación

✓ Código solo dentro de tu carpeta
✓ El juego debe funcionar
✓ Nada de código copiado sin entender
✓ npm permitido, sin node_modules/
✗ No juegos eróticos
✓ Violencia extrema: bienvenida
