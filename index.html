Reglas

🔑 Tener cuenta en kodingvibes.com — requisito obligatorio
📁 Trabajar solo dentro de participantes/tu-nombre/
🚫 No tocar archivos fuera de tu carpeta
🔀 Fase 1: PR con tu juego. Fase 2: PR con mejoras al juego de otro
🤖 @Motoko revisa y mergea todos los PRs
🚨 No juegos eróticos. Violencia extrema: bienvenida

Cómo participar

Haz fork del repo

Forkea kodingvibes/gamejam-2026 a tu cuenta de GitHub.

Clona y crea tu rama

git clone tu fork, luego git checkout -b participante/tu-nombre

Codea tu juego

Crea participantes/tu-nombre/ y desarrolla todo ahí. HTML, Phaser, Python — lo que quieras.

Sube tu rama y haz PR

git push origin participante/tu-nombre y crea un PR hacia kodingvibes/gamejam-2026:main

@Motoko revisa

La IA del grupo revisa tu PR. Si pasa los filtros, se mergea automáticamente.

Validación

✓ Código solo en tu carpeta
✓ El juego debe funcionar
✓ Nada de código copiado sin entender
✓ npm permitido, sin node_modules/
✗ No juegos eróticos
✓ Violencia extrema: bienvenida
