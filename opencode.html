OpenCode + Ollama Cloud

Usa la API remota de Ollama con OpenCode para programar tu juego. Gratis, sin GPU, sin instalaciones pesadas.

PASO 1
Crear cuenta en Ollama Cloud

Regístrate gratis en ollama.com. La capa gratuita incluye crédito suficiente para programar tu juego durante la gamejam sin costo.

Una vez registrado, genera tu API key desde el panel de configuración. La vas a necesitar para conectar OpenCode.

PASO 2
Instalar OpenCode

OpenCode es un asistente de código que se conecta a Ollama (u otros proveedores).

# Con npm / npx:
npx opencode@latest

# O instalación global:
npm install -g opencode
opencode
PASO 3
Configurar OpenCode para usar Ollama Cloud

Crea o edita el archivo de configuración de OpenCode (normalmente ~/.config/opencode/config.json o opencode.json en tu proyecto):

{
  "provider": "ollama",
  "ollama": {
    "model": "minimax/m2.5",
    "baseUrl": "https://api.ollama.com/v1",
    "apiKey": "tu-api-key-de-ollama"
  },
  "systemPrompt": "Eres un desarrollador experto en Phaser 4 y JavaScript. Escribe código limpio, modular y funcional. Responde en español."
}

Reemplazá tu-api-key-de-ollama con la API key que generaste en ollama.com.

El modelo recomendado es minimax/m2.5 — corre en los servidores de Ollama, no necesita GPU local y tiene buena calidad para código. Podés cambiarlo por cualquier modelo disponible en Ollama Cloud.

PASO 4
¡A programar!

Dentro de la carpeta de tu juego, ejecuta OpenCode y empieza a pedirle cosas:

cd participantes/tu-nombre/
opencode

Ejemplos de prompts para tu juego:

"Crea un juego de plataformas con Phaser 4 donde el personaje salte entre plataformas y recolecte monedas."
"Agrega un sistema de puntuación que se muestre en pantalla."
"Haz que el fondo tenga un efecto parallax con 3 capas."
"Agrega un enemigo que patrulle horizontalmente."

Tips para mejores resultados

Contexto es clave: Al empezar una sesión, pídele a OpenCode que lea los archivos existentes de tu juego antes de pedir cambios. Así entiende lo que ya tienes.
Sé específico: En vez de "haz un juego", probá con "Crea un juego con Phaser 4 donde el jugador controle una nave que esquiva asteroides. La nave se mueve con las flechas y dispara con espacio."
Iterá: No esperes que el juego salga perfecto de una. Pedí features de a uno, probá, y después pedí mejoras.
Ollama Cloud es gratis: La capa gratuita de Ollama te da crédito inicial sin necesidad de tarjeta. Con minimax/m2.5 vas a tener respuestas rápidas y de calidad sin ocupar tu GPU ni consumir recursos locales.

¿Problemas?

Si la API key no funciona, verificá que la hayas copiado bien desde ollama.com y que tu cuenta tenga crédito disponible en la capa gratuita.

Si querés usar otro modelo, revisá los disponibles en la documentación de Ollama Cloud y cambialo en la config.

Para más ayuda: abrí un issue en el repo.
