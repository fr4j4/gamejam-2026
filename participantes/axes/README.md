# Axes — GameJam 2026

Base vacía en Phaser 4 para empezar la fase 1.

## Probar

Abre `index.html` en un navegador con conexión a internet. Para evitar restricciones de archivos locales, sirve la carpeta con cualquier servidor estático, por ejemplo:

```bash
python3 -m http.server 8080 --directory participantes/axes
```

Luego visita <http://localhost:8080>. Mueve el cuadrado con WASD o las flechas.
