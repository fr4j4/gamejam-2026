OpenCode + Ollama

Usa tu agente local con OpenCode para programar tu juego sin depender de APIs externas.

PASO 1
Instalar Ollama

Descarga e instala Ollama para tu sistema operativo.

Luego descarga un modelo. Para programar juegos en JavaScript/Phaser, recomendamos:

ollama pull qwen2.5-coder:7b
# o si tienes buena GPU:
ollama pull qwen2.5-coder:14b

Otros modelos que funcionan bien: codestral:latest, deepseek-coder:6.7b, llama3.1:8b.

PASO 2
Instalar OpenCode

OpenCode es un asistente de código que se conecta a Ollama (u otros proveedores).

# Con npm / npx:
npx opencode@latest

# O instalación global:
npm install -g opencode
opencode
PASO 3
Configurar OpenCode para usar Ollama

Crea o edita el archivo de configuración de OpenCode (normalmente ~/.config/opencode/config.json o opencode.json en tu proyecto):

{
  "provider": "ollama",
  "ollama": {
    "model": "qwen2.5-coder:7b",
    "baseUrl": "http://localhost:11434"
  },
  "systemPrompt": "Eres un desarrollador experto en Phaser 4 y JavaScript. Escribe código limpio, modular y funcional. Responde en español."
}

Si quieres usar un modelo diferente, cambia el nombre del modelo en ollama.model.

PASO 4
¡A programar!

Dentro de la carpeta de tu juego, ejecuta OpenCode y empieza a pedirle cosas:

cd participantes/tu-nombre/
opencode

Ejemplos de prompts para tu juego:

"Crea un juego de plataformas con Phaser 4 donde el personaje salte entre plataformas y recolecte monedas."
"Agrega un sistema de puntuación que se muestre en pantalla."
"Haz que el fondo tenga un efecto parallax con 3 capas."
"Agrega un enemigo que patrulle horizontalmente."

Tips para mejores resultados

Contexto es clave: Al empezar una sesión, pídele a OpenCode que lea los archivos existentes de tu juego antes de pedir cambios. Así entiende lo que ya tienes.
Sé específico: En vez de "haz un juego", probá con "Crea un juego con Phaser 4 donde el jugador controle una nave que esquiva asteroides. La nave se mueve con las flechas y dispara con espacio."
Iterá: No esperes que el juego salga perfecto de una. Pedí features de a uno, probá, y después pedí mejoras.
Modelos locales vs APIs: Los modelos locales (7B-14B) son más lentos pero gratuitos y funcionan offline. Si tenés acceso a APIs como Claude o GPT-4, los resultados serán mejores — pero para un juego de gamejam un modelo local de 7B alcanza bien.

¿Problemas?

Si OpenCode no encuentra Ollama, verificá que Ollama esté corriendo:

ollama list
# Si no aparece tu modelo, descargalo con ollama pull <modelo>

Si el modelo responde pero lento, probá con un modelo más chico (qwen2.5-coder:1.5b o llama3.2:3b).

Para más ayuda: abrí un issue en el repo.
